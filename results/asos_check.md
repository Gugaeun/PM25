# 기상청 ASOS를 실시간 모델에 쓸 수 있는지 확인 (적용하지 않음)

## 1. 학습 데이터와 ASOS 서울(108) 값의 일치도

| 기간 | 변수 | 상관 | 학습 데이터 평균 | ASOS 평균 |
|---|---|---|---|---|
| 2025-12 | temp | 0.99 | 1.64 | 1.30 |
| 2025-12 | humid | 0.98 | 56.02 | 61.48 |
| 2025-12 | ws | 0.76 | 1.52 | 2.35 |
| 2025-12 | wind_u | 0.91 | 0.27 | 0.67 |
| 2025-12 | wind_v | 0.14 | -0.43 | -0.80 |
| 2026-09 | temp | 0.99 | 23.04 | 22.55 |
| 2026-09 | humid | 0.97 | 58.54 | 60.90 |
| 2026-09 | ws | 0.80 | 1.39 | 2.24 |
| 2026-09 | wind_u | 0.91 | -0.33 | -0.74 |
| 2026-09 | wind_v | 0.33 | -0.24 | -0.85 |

기온·습도는 잘 맞고, 풍속은 ASOS가 약 0.8m/s 크며(관측소 한 곳 vs 25개 구 평균), 풍향 성분(wind_v)은 거의 맞지 않는다.

## 2. 입력 기상 값을 바꿨을 때 24시간 평균 MAE (2026-01~09, 시점 2161개, persistence 6.65)

| 입력 | MAE |
|---|---|
| 학습에 쓴 기상 값(25개 구 평균, 이상적인 경우) | 5.83 |
| ASOS 값 그대로 | 7.40 |
| ASOS, 바람은 평균비(k=0.64)로 보정 | 6.30 |
| ASOS 기온·습도, 바람은 평균 상수 | 6.19 |
| PM2.5 전용 모델(현재 실시간 모델) | 5.98 |

결론: 이상적인 기상 값이 있어도 PM2.5 전용 모델 대비 개선은 약 2.5%이고, ASOS 값은 어느 방식으로 넣어도 PM2.5 전용 모델보다 나쁘다. 그래서 실시간 화면은 PM2.5 전용 모델을 유지한다. (ASOS 한 관측소와 학습 데이터의 25개 구 평균은 정의가 달라 입력 분포가 어긋남. ASOS로 다시 학습하는 것은 하지 않았다.)
